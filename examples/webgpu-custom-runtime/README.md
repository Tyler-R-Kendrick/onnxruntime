# webgpu-custom-runtime example

This directory is reserved for a minimal app that toggles between stock and custom JSEP artifacts via runtime path override.

## Planned controls
- runtime artifact selector (stock/custom)
- KV compression toggle
- KV compression parameters (mode, bits, group size, layers, debug)

## Current status
Configuration surfaces are implemented in ORT Web option plumbing; interactive sample wiring is pending.
